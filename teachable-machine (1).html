Como funciona

Teachable Machine reconhece a pose → este site verifica a confiança → procura o comando configurado → envia pelo Bluetooth UART → o micro:bit executa.

O limite padrão é 75% de confiança. Você pode alterar abaixo.

⚠️ Importante sobre o Bluetooth

O Chrome/Edge só permite Web Bluetooth em páginas seguras (HTTPS) ou localhost. O micro:bit precisa estar com o Bluetooth UART Service iniciado. No MakeCode, use bluetooth.startUartService().
